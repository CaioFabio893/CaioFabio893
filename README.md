## Projetos em destaque

### Monitoramento de ninhos de tartarugas

Aplicação para um projeto social de conservação, com registro de ninhos, transferências, visitas e eclosões. Permite trabalhar offline e sincronizar os registros posteriormente, com tratamento explícito de conflitos.

**Tecnologias:** TypeScript, React, Vite, Firebase e IndexedDB.

**Destaques:** PWA instalável, mapas, controle de acesso e relatórios em PDF, Excel, JSON e CSV.

[Ver código e documentação](https://github.com/CaioFabio893/app-tartaruga) · [Acessar aplicação](https://monitoramento-de-tartarugas.web.app)

### Gestão de treinos e nutrição

Plataforma com área administrativa para organizar alunos, exercícios, programas, treinos e dietas. Os alunos consultam os conteúdos vinculados à sua conta.

**Tecnologias:** Go, Next.js, TypeScript, Firebase Authentication, Firestore e Google Cloud Run.

**Destaques:** separação entre frontend e API, autenticação e controle de acesso por perfil.

[Ver código e documentação](https://github.com/CaioFabio893/App-treino-nutricao)
